4.3 观测 Hessian 谱分解（偏差的定量解释）

窗口线性化 Y(A) ≈ Y(A_true) + S(A−A_true)，记 H = Sᵀ Q S，则 A* = Σᵢ [λᵢ/(λᵢ+Ca)] (vᵢᵀ A_true) vᵢ —— 收缩因子就是 λᵢ/(λᵢ+Ca)。

机理：打靶式力矩估计的观测 Hessian 天然病态（κ≈682）。 A_true 约 99% 的能量落在 λ < Ca 的特征方向上，这些方向被 1/(1+Ca/λᵢ) 近乎抹平 —— 这正是论文自述的 「P 是防止力矩过大的正则项」在起作用，是方法的固有特性，不是复现错误。

4.4 步长 dt 扫描

CAD 的交互阻尼时间常数 M/K1 = 5.666 ms，论文 5.200 ms。 显式欧拉要求 dt ≪ M/K1；当前 dt=10 ms 使离散速度极点 1−dt·K1/M = -0.765 （负号 = 速度逐步符号交替）。

同事问「这个动力学建模是用 MATLAB / Ansys / SolidWorks 还是别的」。 答案是：整条链路都用 Python，不依赖 MATLAB、Ansys 或 SolidWorks。

环节本实现用的工具说明
几何解析（STP → 质量属性）gmsh 4.15.2（内置 OpenCASCADE 内核） STEP 是中性格式，可直接读入并算体积/质心/惯量，无需 license、可进 CI。 SolidWorks 只是作者导出 STP 时用的工具，本侧不需要。
动力学前向 + 参数反演numpy / scipy.optimize（L-BFGS-B） 模型只有 2 自由度，Python 足够；解析伴随梯度使每个窗口求解 < 0.1 s。 MATLAB 需 license、脚本化/版本控制体验差、无法直接进 CI。
柔性体 / 接触 / 应力本复现不需要 论文模型是刚体 2-DOF M q̈ + C q̇ + G(q) = T − T_int； Ansys 仅在需要柔性变形/接触碰撞/强度校核时才必要。
报告与可视化matplotlib + 自包含 HTML 产物可 diff、可进 git、可评审，便于后续接自动跑批。
一句话：动力学建模不需要 MATLAB/Ansys。STP 只作为几何真值来源， 之后「解析 → 质量属性 → 参数反算 → 力矩估计 → 报告」全是 Python，零 license 依赖。
