# 修法（按推荐顺序）

A. ★ 首选：把 SolidWorks 里那几个零件的「配置名」改成纯 ASCII 再重新导出。
   坏字节来自配置名 —— 插件把它拼进 Name/文件名时吐出了原始字节。
   操作：SolidWorks 打开零件 → 配置管理器 → 右键配置 → 属性 → 改名为
   Default / cfg1 这类纯 ASCII → 保存 → 重新导出。

B. 省事版：把 .SLDASM 另存为纯 ASCII 文件名再导出（顺带解决 XML 名带中文）。

C. 应急版（先跑通流程用）：把 XML 里那 10 个控制字符替换成 ?，
   并同步重命名磁盘上对应的 .STEP，使引用与文件名一致。
   注意：这只修"合法性"，不改几何/质量，但不解决源头。
