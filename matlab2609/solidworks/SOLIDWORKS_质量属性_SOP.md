# SolidWorks 侧 SOP：导出「髋关节质量属性」供 MATLAB 反算 M / G_amp

> 目标：把装配体里**随髋屈伸摆动的零件**的 质量、质心、绕髋轴惯量，导出成一份 CSV，
> 交给 MATLAB 的 `exo2609.params_from_csv`，得到论文模型的 `M`（惯量矩阵）与 `G_amp`（重力矩幅值）。
>
> 关键只有一句话：**先把参考坐标系放到髋轴上、Z 轴对准髋屈伸轴**，之后 SolidWorks
> 报出的「绕输出坐标系 Z 轴的惯量」就直接是你要的 `I_hip`。

---

## 0. 前置：把单位设成 mm + kg

`工具 → 选项 → 文档属性 → 单位`
- 选 **MKS**（保证质量单位是 **kg**）
- 再把 **长度** 单独改成 **毫米 (mm)**

这样惯量的单位自然是 **kg·mm²**，正好是我们 CSV 要的单位。

> ⚠ 不要选 MMGS —— 那是 mm + **克(g)**，质量会差 1000 倍。

---

## 1. 给每个零件指定材质（否则质量是 0）

装配体里逐个零件：右键零件 → **编辑零件** → 右侧材质栏 → **编辑材质** → 选材料。

参考密度（本机 STP 解析时用的假设，按零件名关键字匹配）：

| 类别 | 密度 kg/m³ | 典型零件名关键字 |
|---|---|---|
| 铝合金 | 2700 | `腿部_腿杆` `滑块` `滑轨` `轴盖` `连接件` |
| 钢 / 紧固件 / 轴 | 7850 | `出轴` `螺丝` `轴承` |
| 黄铜 | 8500 | `黄铜轴套` |
| 尼龙 / 织物 | 1150 | `绑缚` |
| 工程塑料 | 1200 | `按键` |
| 电子件（PCB 等） | 1500 | `电控` `PCB` |

> 如果没有对应材质库，用 `评估 → 质量属性 → 覆盖质量属性` 直接输入密度。

**这一步的密度是可配置假设**：`M` 与 `G_amp` 都与密度**成正比**，换一张密度表就是整体线性重标定。
报告里请显式标注「密度来源 = 假设/材质库」。

---

## 2. 建立「髋关节参考坐标系」← 最关键的一步

`插入 → 参考几何体 → 坐标系`

| 项 | 选什么 |
|---|---|
| **原点** | 髋屈伸轴**线上任意一点**（推荐：电机输出轴端面的圆心） |
| **Z 轴** | 髋屈伸轴本身 —— 点选 `电机_出轴` 的**圆柱面**，SolidWorks 会给出其轴线 |
| X / Y 轴 | 任意与之正交的方向（**不影响惯量结果**，只影响 cx / cy 的分配） |

> 本机 STP 里这条轴由左右腿 `电机_出轴`（半径 22 mm）的圆柱面拟合得到，
> 残差 **0.0000 mm**。方向 ≈ **+Y**（模型里 Y 是左右方向，双腿 y ≈ ±217 mm，髋宽 434 mm）。

**为什么必须这样设**：设好之后，质量属性里「**关于输出坐标系**」的 `Lzz`
就是绕髋轴的转动惯量（已含平行轴项），不用再手算。而且
`hypot(cx, cy)` 直接就是髋轴到质心的垂距 `d`，`G_amp = m·g·d` 一步得到。

---

## 3. 打开质量属性，逐组读取

`评估 → 质量属性` → 点 **选项**：

- ☑ 使用自定义坐标系 → 选上面建的 **髋关节参考坐标系**
- ☑ 显示惯性张量
- ☑ 在质心处创建惯性主轴

记录三块数：

| 需要的量 | 在对话框里的位置 | 用途 |
|---|---|---|
| **质量** | 顶部 | `m` |
| **质心 (x, y, z)** | 质心一行 | `d = hypot(cx, cy)`，`G_amp = m·g·d` |
| **惯性矩（关于输出坐标系）** | 惯性矩段 | **`Lzz` → 这就是绕髋轴的惯量 `I_hip`** |
| 惯性矩（关于质心） | 惯性矩段 | 用于自检（见第 6 节） |

> `Izz_com`（关于质心） + `m·(cx²+cy²)` 必须等于 `Izz_O`（关于输出坐标系）。
> 两者对不上 > 1% → 坐标系没设对，或零件漏选。

---

## 4. 分组规则：哪些零件算「摆动件」

论文模型是 **2-DOF（左髋 + 右髋）**，`M` 与 `G_amp` 只统计**随髋屈伸一起摆动**的部件：

| 分组 | 包含 | 是否进 `M` / `G_amp` |
|---|---|---|
| `leg_L` / `leg_R` | 该侧腿杆、绑缚、滑块、滑轨、轴盖、电机出轴、螺钉垫片… | ✅ 是 |
| `motor_L` / `motor_R` | 电机本体（含电控板） | ❌ 单独记录 |
| `back` | 腰带、背板、电池、主机 | ❌ 单独记录（在躯干上，不随髋转） |

> 判定口径：**只问「髋关节转动时，这个零件跟着转吗？」**
> 跟着转 → 进 `leg_*`；不转 → 进 `motor_*` / `back`。
>
> 小技巧（视版本）：在装配体里**先框选**该组零件，再 `评估 → 质量属性`，
> 部分版本会直接对选中零部件计算合计值 —— 比逐个加总快且不易漏。

## 5. 填 CSV / 用宏批量导出

### 5a. 手工填（少量零件足够）

用模板 `mass_props_template.csv`，一行一个零件（或一行一组）：

```
group,part,material,mass_kg,cx_mm,cy_mm,cz_mm,Ixx_com,Iyy_com,Izz_com,Ixy_com,Ixz_com,Iyz_com,Ixx_O,Iyy_O,Izz_O,Ixy_O,Ixz_O,Iyz_O
leg_R,腿部_腿杆_片状V5,6061,0.0870,...,,,,,,,,,,...,...,16975.77,,,,
```

- 分组名必须写 `leg_L` / `leg_R`（MATLAB 侧默认按这两个名字取）
- 惯量填 **kg·mm²**
- 只填 `Izz_com` / `Izz_O` 也能跑（其余分量为空即可）

### 5b. 宏批量导出（零件多时推荐）

见 `export_mass_props.bas`（本仓库附带）。把它导入 SolidWorks 的 VBA 编辑器
（`工具 → 宏 → 新建`，粘贴，运行）即可遍历所有零部件并写出 CSV。

> ⚠ 该宏**未在本机实际运行过**（本机无法自动驱动 SolidWorks GUI）。
> 若报常量名错误，请按报错提示对照 SolidWorks API 帮助里的
> `swMassPropertyMoment_e` 枚举名核对；也可先只用 5a 手工填一份跑通流程。

## 6. 自检清单（做完必查）

1. **整机质量**：各组 `m` 之和应约等于设计重量。本机 STP 解析结果 **3.3140 kg**。
2. **绕轴惯量自检**：`Izz_O ≈ Izz_com + m·(cx²+cy²)`，偏差应 < 1%。
3. **圆柱体校验**（最有效的一招）：单独选 `电机_出轴` 做质量属性，
   它是 r = 22 mm 的圆柱，绕自身轴应是 `(1/2)·m·r²`。
   若报告值与之一致 → **参考坐标系肯定设对了**；差很多 → 回去重设 Z 轴。
4. **本机 STP 基准值**（用同一套密度假设时，你的结果应接近下表）：

| 分组 | m [kg] | d [mm] | I_axis [kg·m²] | G_amp [N·m] |
|---|---|---|---|---|
| `leg_L` | 0.3048 | 185.44 | 0.016976 | 0.5544 |
| `leg_R` | 0.3048 | 185.44 | 0.016976 | 0.5543 |
| `motor_L` | 0.3557 | 6.44 | 0.000378 | 0.0225 |
| `motor_R` | 0.3928 | 6.73 | 0.000439 | 0.0259 |
| `back` | 1.9558 | 159.57 | 0.053777 | 3.0606 |
| 整机 | **3.3140** | — | — | — |

> `leg_L` 与 `leg_R` 的差异应只有第 6 位有效数字（左右对称）。
> 若两者差很多，说明某侧漏选或某零件没赋材质。

## 7. 交给 MATLAB

```matlab
addpath('matlab2609');
p = exo2609.params_from_csv('matlab2609/solidworks/mass_props.csv', 'leg_L','leg_R', 0.01);

% 得到：
%   p.M     = diag([I_hip_L, I_hip_R])        [kg*m^2]
%   p.G_amp = [m_L*g*d_L ; m_R*g*d_R]         [N*m]
%   p.geometry 里挂着每一组的分项，便于复核
```

再跑：

```matlab
selftest2609        % 与已验证基准交叉核对（CSV->M/G_amp、谱分解、离散化）
demo2609_run        % 端到端：正向仿真 + Eq.(6) 滑窗反解 + 谱诊断 + 出图
```

**论文 Table II 对照**：本 CAD 得到 `M = 0.016976`（论文 0.0156，1.088×）、
`G_amp = 0.5544`（论文 0.879，0.631×）。
`K1 = 3I` 无法由几何反算（那是人机交互阻尼），沿用论文并标注来源。

---

## 8. 一个必须知道的坑：`dt`

内部交互阻尼时间常数 `M/K1`：本 CAD **5.66 ms**，论文 **5.20 ms**。
显式欧拉要分辨它需要 `dt ≪ M/K1`；`dt = 10 ms` 时离散速度极点
`1 − dt·K1/M = −0.767`（速度逐步符号交替），轨迹对力矩的响应会被失真放大。

| dt | 极点 | Eq.(6) 复原误差 | 收缩比 |
|---|---|---|---|
| 10 ms | −0.767 | 0.889 | 0.111 |
| 5 ms | +0.116 | 0.797 | 0.204 |
| 2 ms | +0.647 | 0.476 | 0.539 |
| **1 ms** | **+0.823** | **0.238** | **0.818** |

**结论：请用 dt ≤ 1.4 ms（≥ 707 Hz）**，或对 `K1·qd` 阻尼项做隐式/半隐式积分。
MATLAB 里用 `exo2609.discretization_info(p)` 随时复查。
