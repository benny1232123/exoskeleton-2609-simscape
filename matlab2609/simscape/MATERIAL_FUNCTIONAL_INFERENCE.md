## 1. 方法：三个**不依赖零件名**的判据

| # | 判据 | 怎么读 |
|---|---|---|
| A | **bbox 填充率** = V / (bx·by·bz) | 实心轴 ~74%、薄板 ~1–5%、框架 ~10–20%、块 ~34% |
| B | **配合关系** | 谁是谁的配合件？滑动副必须是**异种材料**（铝对铝会咬合 galling） |
| C | **名称语义** | "黄铜"、"注塑"、"绑缚"、"麦拉片"、"顶丝" 等直接给出材料族 |

### ★ 为什么不能只靠名字：关键字表有个**结构性漏洞**

`exo2609/geometry.py: DEFAULT_DENSITIES` 是**按子串顺序匹配、先命中先算**：

```python
(("螺丝","螺钉","螺母","螺柱","顶丝","销","卡簧","垫片","弹垫","平垫","轴套","出轴"), 7850.0, ...)
FALLBACK_DENSITY = 2700.0   # 铝
```

钢铁组的键里有 **`轴套`** 和 **`出轴`**，**唯独没有裸的 `轴`** ⇒
`电机_轴` 一个关键字都没命中 → **静默落到兜底铝**。
这不是"猜错密度"，是**匹配规则漏了一类件**（而且漏掉的是本机的**电机轴**）。
反过来也不能简单往表里加 `轴` —— 那样 `腿部_轴盖` 会被一起拉到钢，而轴盖功能上应是铝。
⇒ **正确修法是加一层"精确名覆盖"，见 §5。**

### 三条硬结论（几何可证，不是推测）

1. **8 号轴套 = Ø8 内孔空心管**（506.68 vs 508.94 mm³，99.6%）→ 它的配合轴**必然**是 9 号 `电机_轴`。

3. **4/5/6 号同宽 30.1–30.4 mm** → 它们是**同一个导轨副装配**（电机→腿杆过渡板 / 导块 / 导轨），

> 所以"滑块铝 + 滑轨铝"这个当前组合**物理上不成立**——
> 只能是「钢轨 + 铝滑块」或「铝轨 + POM/青铜滑块」。**这是本轮最有价值的一条推断。**

## 5. 建议的代码修法：加"精确名覆盖"层

不建议往关键字表里塞裸 `轴`（会误伤 `轴盖`）。正确做法是**在关键字表之前插一层精确匹配**：

```python
# exo2609/geometry.py

# ★ 精确名覆盖（优先于关键字表）。只放"语义明确 + 已排除歧义"的件。
#   加一件前问自己：这件的材料能从名字/功能唯一确定吗？不能就别放，让它走关键字表并标记。
PART_EXACT: Dict[str, Tuple[float, str]] = {
    "电机_轴":              (7850.0, "steel shaft (exact)"),
    "电机_出轴":            (7850.0, "steel output shaft (exact)"),
    "电机_黄铜轴套8_10_18":  (8500.0, "brass bushing (exact)"),
}


def density_of(part_name: str, table=DEFAULT_DENSITIES, fallback=FALLBACK_DENSITY):
    if part_name in PART_EXACT:                      # ★ 新增：精确名优先
        return PART_EXACT[part_name]
    up = (part_name or "").upper()
    for keys, rho, label in table:
        for k in keys:
            if k.upper() in up:
                return rho, label
    return fallback, FALLBACK_LABEL
```

**为什么这样更好**：现在的关键字表是"子串 + 顺序"的，改一处可能误伤别的件（`轴` → `轴盖`），
而且**落在兜底值的件不会报警**。加精确层之后，"哪些件是明确认过的"变成一份**可审阅的清单**。

**配套建议（低成本、防再犯）**：让 `_stp2urdf.py` / `_stp2plant.py` 在收尾打印
**"落到兜底密度的件 + 占质量比"**。现在的兜底是**静默**的，正是因为静默，
54.87% 的质量压在猜测上这事才拖到现在才被发现。

### ★★ 更正：**不是"改一处即可"** —— 密度表在全仓有 **5 个副本**

起草本文时我写了"改一处即可"，`grep` 一验就发现是错的。
